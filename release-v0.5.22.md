# PaperFlux Server 0.5.22

Исправлено подключение и передача данных через Mail.ru Документы:

- Устранена ошибка формата пакетов и heartbeat, вызывавшая отключение после авторизации с кодом `4004`.
- Улучшено распознавание страницы ограничения запросов Mail.ru (`429`).
- Проверено восстановление соединения после обрыва.

Обновите также [Android-клиент до 0.4.35](https://github.com/Flofyyk/PaperFluxAndroid/releases/tag/v0.4.35). Для этого исправления необходимы обновлённые клиент и сервер.

Доступны сервер и сервис выдачи профилей для Linux `amd64` и `arm64`. Контрольные суммы — в `SHA256SUMS-Server.txt`.
